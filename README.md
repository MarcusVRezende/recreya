# 🎈 Recreya 

Repositório central para o desenvolvimento do site de portfólio da **Recreya**, empresa focada em serviços de recreação.

---

## 🎨 Design e Referências
O projeto visual foi desenvolvido no Figma e serve como o guia principal para a implementação de componentes, cores e tipografia:
* 🔗 [Arquivo Figma do Projeto](https://www.figma.com/design/4ERE0utyadqUiBPKlUtR27/Recreya?t=Ln24FDwQSXIfQCAi-0)

---

## 🛠️ Tecnologias Utilizadas
* **React** (Biblioteca principal)
* **Vite** (Ferramenta de build e servidor de desenvolvimento rápido)

---

## 🚀 Como Executar o Projeto Localmente

Siga estes passos para rodar o projeto na sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/MarcusVRezende/recreya.git
2. **Instale as dependências:**
   ```bash
   npm install
3. **Inicie o servidor de desenvolvimento:**
    ```bash
   npm run dev
  O site estará disponível em http://localhost:5173.
